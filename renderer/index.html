                    Outlook calendar

                    Easiest option: MeetNotes reads your calendar from Outlook on this computer. No sign-in, no setup and no administrator approval. Works with classic Outlook for Windows. MeetNotes can only read the calendar.

                    Other options: Microsoft account sign-in or a published calendar link

                    Use these if you use the new Outlook, Outlook on the web only, or another computer.

                    How to get the Application ID (about five minutes, once)
                    1. Open entra.microsoft.com and go to App registrations, then New registration. Name it MeetNotes.
                    2. For a work account, choose "Accounts in this organizational directory only". For a personal Outlook.com account, choose the option that includes personal Microsoft accounts. Leave the redirect address empty.
                    3. Open Authentication and set "Allow public client flows" to Yes. Save.
                    4. Open API permissions, Add a permission, Microsoft Graph, Delegated, and add Calendars.Read and User.Read. MeetNotes never asks to change your calendar.
                    5. Copy the Application (client) ID and the Directory (tenant) ID from the Overview page into the two boxes above. Menu names can differ a little between Microsoft portal versions, and some organisations require an administrator to approve the permission.

                    In Outlook on the web: Settings, Calendar, Shared calendars, Publish a calendar, then copy the ICS link. The link works like a password for your calendar, so MeetNotes stores it encrypted. Your organisation may not allow publishing.

                    AI summary

                    OpenAI: keep the default address. Azure OpenAI: use https://YOUR-RESOURCE.openai.azure.com/openai/v1 and your deployment name as the model. Local models: Ollama is http://localhost:11434/v1 and LM Studio is http://localhost:1234/v1, no key needed.

                    Install once in PowerShell: npm install -g @anthropic-ai/claude-code for Claude Code, or npm install -g @openai/codex for Codex. Then run claude or codex once and sign in. MeetNotes sends the meeting text to it and reads the reply.

                    Templates add sections for a kind of meeting, such as blockers for a standup. You can change the template of each meeting on its Summary tab. To make your own, open the templates folder, copy the example, rename it to end in .json and edit it.

                    Using Microsoft Copilot, ChatGPT, Claude.ai or another tool without a connection? On the Summary tab, choose "Copy prompt for any AI", paste it into the tool, copy the whole reply, then choose "Paste AI reply".

                    Speech

                    The speech model downloads once, the first time you start a meeting, and then runs on this computer.

                    Floating widget

                    A small always-on-top recording widget shows the timer and controls while a meeting is live.
