      The token is stored encrypted on this computer. The simplest safe setup is to create an empty private repository on github.com and use a fine-grained token limited to that repository with Contents set to read and write. Letting the app create repositories needs extra permission; the exact permission name is data to be confirmed, so a classic token with the repo scope is the fallback.
